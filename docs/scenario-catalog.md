# 行业场景目录首片详细需求

附件 02 的 UI02、STD01、STD02 和 STD04 要求用户依据用途、行业、规则和交付对象创建任务。原 PRD 的 CFG-01、CFG-02 已设计行业配置及历史版本锁定。当前运行版只有固定演示场景，首片把已发布的场景版本接到受权限控制的目录。规则判断、政策维护和客户页选择器各自按后续切片实施。

## 用户流程

企业成员进入获授权的组织。目录返回已发布场景，可按行业选择。用户可比较任务用途、交付对象和适用性待确认提示，然后用选定版本发起受理。用工业制造的采购方资料准备和建筑物业的组织盘查准备两条合成路线验证。采购方只是第一条路线的交付对象。可新增其他行业与用途配置。

## API 和数据

`GET /v1/customer/scenarios?orgId=<uuid>` 返回 `200 { items }`。目录为空时返回空数组。授权沿用企业端组织 customer 角色，无权限返回 403。每项包含 `id`, `code`, `version`, `industryCode`, `industryName`, `title`, `purpose`, `recipient`, `ruleStatus`。`ruleStatus` 固定为 `needs_review`。响应不提供规则适用结论、签发资质或原始配置字段。

复用 `carbon.scenario_release` 的租户、代码、发布版本和不可变 ID。配置方在发布时写入 `manifest.catalog`，其中行业编码、行业名称、场景名称、用途及交付对象均为必填文本。目录按每个代码的最新已发布版本判断其是否含目录配置。旧版任务始终保存原 `scenarioReleaseId`，原有创建请求继续接受有权访问的既有版本。对外发布流程与规则生效、撤销及专业审批另列验收。

## 放行验收

1. 同一组织可以看到两条不同行业、用途和交付对象的路线。添加新版本后，目录返回最新版本，原任务仍指向旧版本。
2. 同租户中未授权该组织的企业成员以及另一租户的数据相互不可见。无角色的请求返回 403。
3. 旧配置缺少目录字段时不列入目录，既有受理兼容。最新版本无目录配置时，不回退展示旧入口。
4. 全部条目标记待确认。目录数据中的其他字段不会被透传，界面可通过公开契约开发，API Agent 可用相同字段选择场景。

## 四项资料受理扩展

本机演示租户发布四个场景。模块页通过 `/customer?scenarioCode=<code>` 打开企业受理表单，按当前组织目录解析最新发布版本，预选行业和场景并填写可编辑用途。提交表单时仍保存具体的 `scenarioReleaseId`。既有 `?scenario=<uuid>` 链接可继续使用。代码未匹配时，提示用户手动选择。

| 业务 | 场景代码 | 首片准备材料 | 可核对的参考来源 |
| --- | --- | --- | --- |
| 碳核查 | `verification-prep` | 待核查报告、原始凭证、数据修订记录 | [钢铁行业核查指南](https://www.mee.gov.cn/xxgk2018/xxgk/xxgk06/202501/W020250124388843909905.pdf)，仅作该行业范围的参考 |
| 碳交易与履约 | `compliance-prep` | 履约期间、适用机制、配额与官方记录 | [碳排放权交易管理暂行条例](https://www.mee.gov.cn/zcwj/gwywj/202610/t20261010_1175967.shtml) |
| 零碳管理 | `zero-carbon-prep` | 设施或园区边界、用能基线、目标及措施 | [关于开展零碳园区建设的通知](https://www.ndrc.gov.cn/xxgk/zcfb/tz/202507/t20250708_1399055.html)，用于园区建设参考 |
| ESG 与可持续披露 | `esg-disclosure-prep` | 披露期间、适用框架、重要议题及指标证据 | [企业可持续披露准则——基本准则（试行）](https://kjs.mof.gov.cn/zhengcefabu/202412/t20241216_3949745.htm) |

验收逐项核对已选版本、对应参考原文、材料登记、受理提交、独立复核退回及审计。专业复核的对象是受理资料，政策适用性仍待确认。正式核查、交易及清缴、零碳项目管理和 ESG 披露分别按其专项流程实施。其他租户需通过各自的授权发布流程配置场景。

## 产品足迹与境外买方资料分流

| 入口 | 场景代码 | 材料和报告要求 | 原文依据 |
| --- | --- | --- | --- |
| 产品碳足迹 | `product-footprint-prep` | 产品型号、功能单位、生命周期边界、物料、工序及证据。准备说明分配方法、数据来源和限制 | [GB/T 24067-2024 发布信息](https://www.mee.gov.cn/xxgk/hjyw/202409/t20240910_1085619.shtml) |
| 境外客户报告 | `overseas-report-prep` | 买方邮件、模板、语言、期限、报告对象和数据范围。先明确设施排放、产品足迹、CBAM 数据或 ESG 问卷，再核对验证要求与交付授权 | [欧盟 CBAM 正式阶段指引](https://taxation-customs.ec.europa.eu/carbon-border-adjustment-mechanism/cbam-definitive-regime_en)，仅在买方明确索取 CBAM 数据时作为参考 |

目录可选返回 `preparation: { materials: string[], reportRequirements: string[] }`。两个数组须非空且每项为非空文本，其他配置字段不透传。未配置或格式不符时省略该字段，旧客户端和既有买方任务保持兼容。工作台在选定场景后显示该版本的准备清单。保存受理时固定发布 ID，适用规则仍为待确认。清单用于受理准备，正式核算、签发、监管申报与对外共享各自验收。
