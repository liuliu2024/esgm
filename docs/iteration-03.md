## 阶段三 E01 范围

已切回两位开发继续实现。客户仅可为本人名下、仍获授权且处于草稿或退回状态的任务登记材料清单。新登记项统一为**待补文件**。查询遵循已有任务可见权限。登记项追加保存并禁止修改。此片只记录待补材料，文件上传、核验结果和正式引用另行实现。

| 验收项 | 合格证据 |
|---|---|
| E01.1 登记入口 | 本人在获授权的草稿或退回任务可登记。已提交或已批准任务、他人任务及无权任务均不能登记 |
| E01.2 可见范围 | 客户与专业作业台按各自任务可见性查询。跨租户、同租户异组织和撤权后不可访问 |
| E01.3 状态与不可变 | 新项状态为待补文件。读取可复现登记内容。服务与数据约束拒绝原地修改或删除 |
| E01.4 能力边界 | 接口与界面只显示登记状态，不能上传或生成文件、伪造核验结果、生成正式引用 |
| E01.5 迁移与回归 | 空库和阶段二已有数据的库可执行增量迁移。既有受理、补正、复核及审计路径不回归 |

数据库开发交付迁移、隔离与不可变约束。服务开发交付登记和列表契约、状态及错误语义。开发完成释放席位后，QC、数据库测试、接口测试分别独立评审或验证，再由项目管理岗收口。涉及 UI 接续时由前台团队按冻结的接口和状态推进。
