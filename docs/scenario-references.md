# 场景资料原文与版本

对应 UI03、STD01–04 和 CAL01 的来源要求。首片给企业用户提供可查的原文和口径说明，帮助用户在创建受理前判断要向专家确认哪些事项。资料随已选场景版本固定。后续由专家在明确主体、用途、地域、期间、规则版本后另行保存适用结论。

`GET /v1/customer/scenarios/:id/references?orgId=…` 返回 `{scenarioReleaseId,ruleStatus,items}`。有效的组织客户角色可以查询本租户的指定发布版本。缺组织权限返回 403，其他租户或不存在的版本返回 404。旧版本仍可读。没有资料配置时返回空数组。`ruleStatus` 固定为 `needs_review`。

`scenario_release.manifest.references` 使用按展示顺序的数组，每项为 `code,title,publisher,sourceUrl,scopeNote`，其中 `sourceUrl` 必须为无凭据的 HTTPS 链接，输出只包含约定字段。资料维护使用现有受信场景发布入口。旧版或不完整条目不透传。此功能不请求外部网站、不自动下载文档、不计算或替换任何因子。

## 首批官方资料

工业制造的采购方资料准备场景提供产品足迹通则发布信息与电力碳足迹因子公告。前者用于确认产品足迹方法，后者用于核对产品口径下的电力因子。核对买方明确要求、具体产品方法、适用时期及许可后再选因子。 [GB/T 24067-2024 发布信息](https://www.mee.gov.cn/xxgk/hjyw/202409/t20240910_1085619.shtml) · [2024 年电力碳足迹因子公告](https://www.mee.gov.cn/xxgk2018/xxgk/xxgk01/202510/t20251024_1130734.html)

建筑物业的组织盘查准备场景提供电力消费二氧化碳排放量的官方参考，提醒按实际报告年度、地域和适用方法复核口径。产品电力碳足迹与组织购电二氧化碳排放的资料分别展示。 [2023 年电力二氧化碳排放因子公告](https://www.mee.gov.cn/xxgk2018/xxgk/xxgk01/202512/t20251231_1139517.html)

验收覆盖两条行业路线及不同资料、固定指定旧版本、跨租户和无组织授权、空配置、非法链接和附加私有字段。核对资料接口不修改合成计算、任务状态或审计。

企业用户选中办理场景后，可以展开“参考资料”查看标题、发布机关、出处和参考范围。资料在用户展开时读取，切换行业或场景清除原资料。空列表、加载和失败各有提示。原文链接由用户主动打开，资料暂时不可读时仍可保存受理草稿。
