# 碳有据底座项目管理和放行记录

## 范围与职责

本轮以 [首个底座纵切需求](./scope.md) 的 F01–F08 为验收基线。交付空库迁移、受理服务和可复现测试，验证授权组织内的草稿、提交、独立复核和成功审计。批准表示受理信息通过。UI 与交互另起阶段，由项目管理岗汇总接口、错误状态及验收结果后交接给对应团队。

项目管理岗维护范围、契约、依赖、缺陷与放行结论。变更先回到项目管理岗，明确责任人、影响和复验范围。需求岗维护验收口径。开发岗负责实现和修复，QC 独立评审，两位测试独立出具验证记录，根代理负责依赖、环境、集成与最终交付。

| 角色 | 工作包 | 完成和交接证据 |
|---|---|---|
| 高级需求分析 | 收口受理纵切、三端授权、F01–F08 | 需求文档已交接；每项验收都可找到实现或明确的待办 |
| 资深数据库开发 | 核心迁移、隔离、状态和审计约束 | 迁移路径、初始数据必填字段、最小权限角色、动作枚举、可执行说明、待验证项 |
| 资深服务开发 | 前台、专业作业台和管理端的用例入口 | 接口与参数样例、可信身份契约、授权与错误映射、已运行检查及缺口 |
| 独立 QC | 审查两份实现及运行接线 | 按严重度记录问题、复现和修复验证。跨租户、跨组织、越权、自审、重复推进及审计不一致列为阻断 |
| 数据库测试 | 实际执行迁移和数据库验证 | 报告数据库类型、版本、角色及测试命令；标记真并发、连接复用、备份恢复是否实测 |
| 接口测试 | 通过公开服务入口独立验证 | 用例、输入、HTTP 语义和数据变化对应。验证两租户、两个组织、撤权、自审、旧版本和错误脱敏 |

## 契约和接力

1. 需求岗交付基线后，数据库与服务开发对齐表、字段和动作。变更同一契约前同步两岗及集成负责人。当前关键约定为 `carbon_app` 最小权限角色、事务本地租户和主体、场景发布版本固定、`draft → submitted → approved / returned`、修订条件更新及 `created / submitted / approved / returned` 成功审计。
2. 服务接入点为 `createCarbonApi(database)`，上下文由可信认证接入层提供。客户与专业人员分别使用业务动作。管理入口单独授权。同一事务承担业务写入和成功审计。
3. 开发提交后，QC 与两位测试按可用席位接力。数据库测试以迁移和运行角色为入口，接口测试以服务和可信上下文为入口。发现缺陷后由原责任岗修复，相关测试复跑，QC 核验阻断问题关闭。
4. 项目管理岗收齐执行结果，逐项标记通过、失败或待验证。并发席位不足时按阶段交接，角色与记录保持独立。

**契约收口。** F02 退回理由已从入口校验写入事务，并可在客户详情和管理审计中查询。数据库与接口独立测试均覆盖，QC 已复核并关闭缺口。管理授权查询只返回管理员本人在组织内的授权，组织全量授权管理另列范围。

## QC 检查

| 检查 | 可接受证据 |
|---|---|
| 用户、开发者和 AI Agent 体验 | 每次修改说明三类使用者的影响并验证相关旧行为。用户得到清楚状态与下一步；开发者能依照接口与迁移复现；Agent 能依据明确的动作、输入和错误契约协作 |
| UI 文字 | 本轮无 UI 修改。后续删除冗余标语、说明和次要标签。删后流程难懂时调整布局、控件或流程，保留影响选择和安全的关键信息 |
| 校验与代码复杂度 | 请求在入口校验，内部使用已校验值和类型契约。数据库守住数据不变量。一次性逻辑就近。抽象有实际复用证据。异常处理限于能恢复、转换或记录的边界 |
| 新增边界条件 | 新的低概率分支或并发防护先记录触发条件、风险与代价，用户确认后再实现。已确认的隔离、独立复核、状态转换和原子审计按主流程验收 |
| 陌生实现 | 实现前比较活跃且许可明确的 GitHub 项目，记录思路、依赖和已知问题。无法核实授权或许可不兼容的代码禁止复制 |
| 回归与缺陷收口 | 修改后的针对性复验及相关回归有命令和结果。失败有复现、责任岗、修复和复验记录；跳过有原因与待办 |

## 放行门

**开发包交付。** 可在干净环境复现迁移和最小业务流；独立评审与两类测试分别出具证据。未完成的 F 项和真实环境验证明确披露，模拟验证、单连接数据库验证与真实多连接 PostgreSQL 分开记录。

**生产试点。** 接入正式认证与组织权限源。真实 PostgreSQL 验证非所有者运行角色、连接池事务上下文、并发转换和撤权。演练迁移、备份恢复、权限与日志。确认客户端重试语义；目前创建重复请求会产生新任务 ID。隔离、权限、独立性或审计一致性任何一项失败均阻断放行。UI 团队接续前以冻结接口、状态、错误与权限矩阵为交接输入。
