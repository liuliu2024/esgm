# RQ04 A 内部管理报告演示稿

依据 RQ04、RPT02–05 和 AT14/15/16。以 RQ03 B 的冻结结果生成内部演示稿，验证管理报告能从结果追溯到输入。首片交付生成和读取的 JSON 接口。站内查看页面由交互切片接入。采购方交付、正式签发和文件导出分别验收。

## 入口和权限

| 动作 | 契约 |
|---|---|
| 生成演示稿 | `POST /v1/customer/cases/:id/internal-report-drafts` 接收 `{orgId,snapshotId}`。从同任务的冻结快照生成中文结构化草稿 |
| 读取演示稿 | `GET /v1/customer/cases/:id/internal-report-drafts/:draftId?orgId=…`，返回该版本冻结内容 |

沿用企业本人任务的读取范围和有效组织客户授权。生成和读取均核对租户、组织、任务和对应标识。客户端只提供标识，数字、因子、来源、模板和标识语由服务确定。组织授权不存在时返回 403，任务、快照或稿件不可见时返回 404。撤权后旧链接和生成重试同样受限。首片无复核人员或收件人的稿件读取入口。

只接受完整覆盖、标为合成且正式报告资格为假的 RQ03 B 冻结结果。未知架构版本或不满足输入要求时返回 409 `REPORT_DRAFT_SOURCE_UNSUPPORTED`，提示选择可用快照。服务直接读取该结果，生成过程不会重新查询最新活动或重算。

## 输出和版本

响应包含 `{draftId,caseId,snapshotId,createdAt,status,mode,formalReportEligible,externalDeliveryEligible,template,report}`。状态固定为 `draft`，模式为 `synthetic`，正式报告资格和外发资格均为 `false`。模板固定为 `{id:"internal-management-demo",version:1,locale:"zh-CN"}`。

| 报告内容 | 输出 |
|---|---|
| 标题和标识 | `title` 为“内部管理报告演示稿”。`watermark` 为“内部演示｜合成因子｜禁止外发”。后续站内页面须在稿件首屏醒目显示，打印接入时须保留 |
| 范围和时间 | `scope` 含任务、起止月、用途和快照冻结时间。范围限于该任务和期间。冻结时间表示本稿所用台账版本的形成时点，业务数据期间和报告创建时间分别显示 |
| 摘要和明细 | `summary` 含覆盖、精确十进制总量及单位。`items` 按月和活动来源保留数量、单位、计算结果、模型和因子版本 |
| 来源 | `lineage` 或明细内的来源引用保留快照、批次、预检修订、源行和活动修订。避免复制原始 CSV、原件下载地址或任务范围外的信息 |
| 限制 | `limitations` 明确使用合成因子、演示模板覆盖、缺少正式适用性审核，及外部交付与正式用途限制 |

首片输出 JSON 供站内呈现。首次生成返回 201，同任务、快照和模板版本重复生成返回原稿及原时间，状态为 200。新快照或新模板生成新稿，旧稿保留原内容。相同源并发生成依唯一键收敛。因合成数据体积有限，首片同步生成；正式多页产物按独立作业处理，作业状态与报告状态分开。

候选表 `carbon.internal_report_draft` 保存 `tenant_id,org_id,case_id,id,snapshot_id,template_id,template_version,created_by,request_id,created_at,payload`。快照以 `(tenant_id,org_id,case_id,snapshot_id)` 复合外键关联，去重键由任务、快照和模板版本构成。写入只追加并实施租户及创建者 RLS。保存冻结内容及首次生成追踪信息。生成失败无新稿件，审批状态、受理状态及既有审计历史保持原语义。

## 后续审批、导出与受控交付

- 正式报告编制要求可用生产因子及许可证、版本化模板、适用规则、核算范围、可复算结果和质量问题状态。合成稿无正式批准入口。编制人提交正式版本，由有权的独立审核人批准。退回保留理由，后续更正另建版本。报告审批和受理复核分别留痕。
- 中文 PDF 先在独立导出切片验证模板、分页、字体、单位、数字和来源一致性。保存不可变文件版本及摘要，并测试下载授权和对象存储恢复。Word、Excel 各自通过同数据契约验收后启用。预览能力与批准文件的导出资格分开。
- 内部批准后的外发另需有权人明确批准具体版本、具名采购方或其他收件人、目的、字段白名单和有效期，生成专用交付件。初始人工交付记录版本与交付凭证，后续线上领取检查收件身份、授权、到期和撤回。能证明的状态按实际记录为创建、领取或送达。外发能力与演示稿隔离。

## 验收

1. 从完整合成快照生成演示稿，核对 `"900"` kgCO2e、`"0.9"` tCO2e、源行、活动修订、快照 ID、模板版本和醒目标识。使用第二个行业任务验证路径复用。
2. 同快照重复和并发生成返回同一稿件 ID、正文和创建时间。活动更正后旧稿不变，新快照生成新稿。验证草稿读取无隐式重算。
3. 测试同租户他人、异组织、跨租户、复核人员直读、撤权和跨任务快照 ID。失败响应不得包含数字、源行或其他任务信息。
4. 生成异常不创建稿件或交付记录。核对任务修订和受理审计不变。确认首片 API 只提供演示稿生成和读取。站内查看、打印、正式批准、文件导出和采购方访问分别验收。
