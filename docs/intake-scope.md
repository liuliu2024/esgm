# 受理范围登记

对应 UI02、STD01 与 ORG01 的受理前置信息。企业成员选场景后可登记报告对象、地区、年度和交付对象，供专业复核时确认口径。资料只记录企业申报范围。适用性、核算对象主数据、汇总及正式报告另行验收。

`POST /v1/customer/cases` 接收原参数和可选 `scope`。其中 `subjectType` 为 `organization|facility|product|project`，`subjectName` 和 `recipient` 为最多 120 字符的非空文本，`jurisdiction` 为最多 80 字符的非空文本，`reportingYear` 为 `0001` 至 `9999` 的四位年份字符串。入口严格接收这五个字段。全部省略则保留原请求和原响应，传入时五项均必填。创建、详情和状态转换响应带已登记的 `scope`。列表仍为原摘要。

以 `carbon.case_intake.intake_scope` 可空 JSONB 列持久化固定的申报记录，与既有租户、组织、任务 ID 同行保存，沿用原权限。历史任务无需回填。列只在创建时写入，数据库阻止原地改动。变更主体、期间或交付对象的流程待单独设计和验收。字段不参与当前合成核算及报告生成，也不触发对外发送。

验收覆盖两条行业路线、旧客户端省略范围、字段缺失或非法、无额外字段、创建者与复核者在各自权限和状态下可读、跨组织及跨租户拒绝、补正重提保留原范围、数据库运行角色和迁移所有者不能原地修改。既有受理状态和审计事件继续一致。
